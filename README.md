# ANVIL

**ANVIL** — ультралёгкий терминал для тех, кто работает в CLI: Claude Code,
OpenCode, OMP и другие агентные оболочки. Вертикальные вкладки, сплиты, панель
git прямо в пейне и статус Claude Code — без Electron, Node и интерпретатора
в поставке: один exe и две dll. Написан на Rust, рисуется через egui/OpenGL,
запускает оболочку на встроенном ConPTY. Автор — rercon prod.

## Возможности

**Вкладки и пейны**
- Вертикальный список вкладок: номера, заголовок, точка активности, бейдж Claude;
  перетаскивание для смены порядка, переименование по правому клику.
- Сплиты вправо и вниз, навигация между пейнами, максимизация пейна,
  сворачивание в чип в полосе над терминалом.
- Неактивные пейны притемняются, чтобы взгляд держался на том, куда печатаешь.
- Сессия восстанавливается при запуске: вкладки, сплиты, рабочие каталоги,
  открытая панель и её вкладка.

**Терминал**
- Полноценный VTE-разбор (`alacritty_terminal`): 256/truecolor, курсор, режимы
  мыши, bracketed paste, OSC 8-ссылки, OSC 7/1337 — панель следует за `cd`.
- Поиск по буферу (Ctrl+Shift+F), скроллбек, выделение мышью, копирование
  по выделению, вставка средней кнопкой.
- Блочные элементы (`█ ▀ ▐ ▛ ▝ …`) рисуются ровно в клетку, поэтому ASCII-арт
  вроде маскота Claude Code собирается в картинку, а не рассыпается.
- Масштаб текста: Ctrl+= / Ctrl+- / Ctrl+0, размер показывается тостом.
- Шрифт интерфейса — Cascadia Mono (вшита), терминал берёт системное семейство
  из настроек; недостающие глифы подтягиваются из системных шрифтов.

**Панель git** (у каждого пейна своя, Ctrl+Shift+G)
- Статус, стейджинг по файлам и **по отдельным ханкам**, дифф с номерами строк
  и полосами изменений, как в привычных difftool.
- Коммит: сообщение вручную или ИИ-командой (`claude`, `opencode`, `codex`…);
  push и fetch, граф коммитов с цветами по секциям (синие — не отправленные,
  бледно-розовые — в истории, сиреневые — входящие).
- Дерево файлов (свёрнуто по умолчанию, поиск — как раньше, по нечёткому
  совпадению), превью файла с нумерацией строк и **рендером Markdown**
  (заголовки, списки, цитаты, код, таблицы, инлайн-разметка), кнопка подсчёта
  строк проекта.

**Claude Code**
- Строка состояния в панели вкладки: модель, заполнение контекста, лимиты 5ч/7д;
  подключается в настройках и умеет вернуть прежнюю команду статус-строки.

## Требования

- Windows 10/11 **x64** (в поставке вендоренный ConPTY; другие архитектуры не
  поддерживаются осознанно — см. `build.rs`).
- Rust 1.88+ с MSVC-тулчейном (для сборки из исходников).

## Сборка

```powershell
cargo build --release          # target\release\anvil.exe
cargo test                     # юнит-тесты, ConPTY и интеграционные git-тесты
cargo run --example gen_icons  # пересобрать иконки из исходного арта в корне
```

Портативный архив с лицензиями и `SOURCE.txt`:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package.ps1
# dist\anvil-<версия>-x64.zip
```

В архиве: `anvil.exe`, `anvil-claude-status.exe`, `conpty.dll`, `OpenConsole.exe`,
`LICENSE`, `LICENSES\**` (включая полный текст OFL для шрифтов) и `SOURCE.txt`.

## Горячие клавиши

Основные (полный список и переопределение — в настройках и `config.json`):

| Действие | Клавиши |
|---|---|
| Новая вкладка / окно | `Ctrl+Shift+T` / `Ctrl+Shift+N` |
| Закрыть / вернуть вкладку | `Ctrl+Shift+W` / `Ctrl+Shift+Z` |
| Следующая / предыдущая вкладка | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Вкладка по номеру | `Alt+1…9`, `Alt+0` |
| Сплит вправо / вниз | `Ctrl+Shift+S` / `Ctrl+Shift+D` |
| Перейти в пейн | `Ctrl+Alt+Стрелки` |
| Максимизировать пейн | `Ctrl+Alt+Enter` |
| Панель git | `Ctrl+Shift+G` |
| Поиск в терминале | `Ctrl+Shift+F` |
| Копировать / вставить | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Масштаб текста | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| Выбор профиля | `Ctrl+Shift+E` |
| Настройки | `Ctrl+,` |
| Полный экран | `F11` |

## Настройки и файлы

- `%APPDATA%\anvil\config.json` — пишутся только значения, отличающиеся от
  умолчаний: шрифт, цветовая схема, профили, горячие клавиши, переключатель
  Claude Code, восстановление сессии, ИИ-команда для сообщения коммита.
  Файл можно править на ходу: приложение перечитывает его и не затирает
  частично записанный файл.
- `%APPDATA%\anvil\session.json` — окна, вкладки, сплиты и каталоги.
- `%APPDATA%\anvil\anvil.log` — журнал (с ротацией).
